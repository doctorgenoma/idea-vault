CONFIGURAR NOTAS

Este cartucho usa el plugin comunitario Advanced URI (instálalo desde Ajustes → Community plugins) para insertar tu idea al principio o al final de la nota.

Para añadir o cambiar notas, abre este archivo .html con un editor de texto y edita la lista NOTES al principio del bloque <script>. Cada nota necesita:

name → título que verás en la cabecera
vault → nombre exacto de tu vault
file → ruta de la nota dentro del vault, sin ".md"
mode → "prepend" (inicio) o "append" (final)

Guarda el archivo y recarga la página: aparecerá una pestaña nueva por cada nota.
